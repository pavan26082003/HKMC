# HKMC Builders and Developers

A modern, responsive real estate website built with React and Tailwind CSS for HKMC Builders and Developers Pvt Ltd.

## 🏢 About

HKMC Builders and Developers is a premium real estate company specializing in open plots and residential projects in Hyderabad. This website showcases our projects and provides lead generation capabilities for potential investors.

## ✨ Features

- **Modern UI/UX**: Clean, professional design with glassmorphism effects and smooth animations
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Project Showcase**: Detailed information about Eden Farms and Deccan Heights projects
- **Investment Calculator**: Interactive tool to estimate future property value
- **Lead Generation**: Multiple contact forms and CTAs for capturing leads
- **Floating Action Buttons**: Quick access to Call and WhatsApp
- **SEO Optimized**: Proper meta tags and semantic HTML structure
- **Smooth Animations**: Scroll-triggered animations using Intersection Observer

## 🛠️ Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **React Router DOM** - Client-side routing
- **Lucide React** - Modern icon library
- **Framer Motion** - Animation library (optional)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/pavan26082003/HKMC.git
cd hkmc-builders
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit:
```
http://localhost:5173
```

## 🏗️ Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist` folder.
